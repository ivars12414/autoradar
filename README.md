# АвтоРадар
Устанавливаемое приложение для личной базы автомобилей Латвии. Работает на телефоне и компьютере, хранит данные в IndexedDB и открывается без интернета после первой загрузки.

## Использование
Откройте опубликованный сайт. Нажмите «Установить приложение» или выберите установку в меню браузера. На iPhone откройте сайт в Safari и выберите «Поделиться → На экран Домой».

Поиск, максимальная цена, сортировка, ТОП-5, избранное, карточки и история цен доступны в приложении. В комплекте нет проверенных реальных объявлений. Кнопка «Добавить демо» добавляет явно отмеченные вымышленные примеры.

## База
«Экспорт JSON» сохраняет резервную копию. «Импорт JSON» сливает данные по стабильному id, объединяет избранное и историю без дублей. Отсутствующие записи не удаляются. Ошибочный файл или ошибка записи не изменяют базу. Для обновления через ChatGPT экспортируйте базу, прикрепите файл в чат и импортируйте полученный JSON. Автоматического поиска и фоновой синхронизации нет.

Данные принадлежат этому браузеру и устройству. Перед очисткой данных сайта сохраните экспорт. Между устройствами базу можно перенести этим же файлом.

## Публикация
GitHub Pages: main, корень репозитория. Сборка и платные API не нужны. Пути манифеста и service worker поддерживают размещение в /autoradar/.

## Проверено
Импорт и экспорт с восстановлением после очистки; повторный импорт; история цен; избранное после перезагрузки; фильтры; карточки; отклонение повреждённого файла; ошибка записи; офлайн-перезагрузка; сохранение кешей других приложений; PNG-иконки 192 и 512.
