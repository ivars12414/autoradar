# AutoRadar 2.0.3

Устанавливаемое приложение для личной базы автомобилей Латвии. Данные хранятся на устройстве в IndexedDB. После первой загрузки приложение работает без интернета.

## Интерфейс
На компьютере разделы расположены слева. На телефоне пять разделов закреплены внизу: Обзор, ТОП-5, Модели, Избранное, Изменения. Внутри ТОП-5 — Кроссоверы / Все кузова. Поиск, цена, сортировка, рейтинги и логика подборок сохранены. Модели показывает прежнюю подборку любимых марок: Volvo, BMW, Nissan, MG.

Обновить — инструкция и действия для обновления объявлений через ChatGPT. База — импорт/экспорт, установка, обновление приложения, демо и очистка. Автоматического поиска объявлений и синхронизации между устройствами нет.

## Обновление установленного приложения
Переустановка не требуется. Подключитесь к интернету, полностью закройте AutoRadar и откройте его заново. Если виден старый экран, откройте опубликованный адрес в том же браузере и обновите страницу, затем снова откройте приложение. При появлении сообщения о новой версии нажмите Перезапустить.

В версии 2.0.3 также доступно: База → Проверить обновление → Перезапустить приложение (если обновление найдено). Текущая версия указана внизу списка и в База. Не удаляйте данные сайта для обновления: в них хранится личная база. При желании сначала сохраните Экспорт JSON.

## Хранение
Имя базы autoradar-local-v1, версия 1, хранилище state, ключ main сохранены. Формат JSON schema_version: 1 не изменён. Импорт объединяет записи по id, историю цен и избранное без дублей. Неверные данные и ошибки записи не меняют текущую базу. Демо-автомобили вымышлены и помечены.

## Публикация и офлайн
GitHub Pages: main, корень репозитория, без сборки. CSS/JS имеют адреса с версией. Service worker кеширует интерфейс; новая версия активируется после закрытия старых окон или по кнопке перезапуска. При следующем релизе измените версию в HTML, JS и имени кеша/списке ресурсов sw.js.

## Проверено
Переход с прежнего service worker и интерфейса без потери базы, избранного и лимита цены; активация обновления; запуск без сети; импорт/экспорт с восстановлением; ТОП-5, поиск, сортировка, нулевая цена, безопасный текст; экраны 320–1280 пикселей; неподвижная нижняя навигация и доступная последняя карточка.

## Срок техосмотра (2.0.3)
Поле ta_until хранит YYYY-MM или точную дату YYYY-MM-DD. ta_source: listing/csdd, ta_source_url, ta_checked_at и ta_evidence сохраняют источник. ta_check_status: found/not_stated/unavailable/conflict. ta_csdd_verified не смешивается с наличием даты в объявлении; прежний ta_verified сам по себе не означает проверку CSDD. Текущий месяц без дня требует уточнения; прошлый срок помечается истекшим. Новые поля необязательны для старых экспортов, импорт проверяет их формат.

## Фильтр города (2.0.3)
Города берутся из активных записей базы. Выбор применяется до формирования ТОП-5 и работает вместе с поиском и ценой во всех разделах. Выбранный город сохраняется в settings.cityFilter и восстанавливается при открытии. Пустые города доступны как «Город не указан». Сброс фильтров возвращает «Все города». Регистр и лишние пробелы в названиях нормализуются; переводы названий не угадываются.
