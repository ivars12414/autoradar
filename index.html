Обновление через ChatGPT

  1. Экспортируй текущую базу.
  2. Прикрепи JSON к сообщению в ChatGPT: «Обнови АвтоРадар по этому файлу».
  3. Импортируй обновлённый файл обратно.

Эта кнопка обновляет объявления через файл. Для обновления самого приложения используй «База → Проверить обновление».
